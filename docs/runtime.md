# Runtime helpers

The generated server exposes two interfaces to your handler functions via
[`pkg/runtime`](../pkg/runtime/handler_func.go).

Handler signature:

```go
func MyHandler(r runtime.Request, w runtime.Response) { ... }
```

---

## Request

| Method                                          | Description                                       |
| ----------------------------------------------- | ------------------------------------------------- |
| `Raw() *http.Request`                           | underlying `*http.Request`                        |
| `Context() context.Context`                     | request context                                   |
| `PathValue(name string) string`                 | path parameter (e.g. `{id}`)                      |
| `QueryValue(name string) (string, bool)`        | query parameter, bool indicates presence          |
| `QueryValueOrDefault(name, def string) string`  | query parameter with fallback                     |
| `Header(name string) (string, bool)`            | request header, bool indicates presence           |
| `HeaderOrDefault(name, def string) string`      | request header with fallback                      |
| `Body() ([]byte, error)`                        | raw request body                                  |
| `FromJsonBody(v any) error`                     | decode JSON body into `v`                         |
| `Form(name string) (string, bool)`              | form field, bool indicates presence               |
| `FormOrDefault(name, def string) string`        | form field with fallback                          |

---

## Response

| Method                                                       | Description                              |
| ------------------------------------------------------------ | ---------------------------------------- |
| `Raw() http.ResponseWriter`                                  | underlying `http.ResponseWriter`         |
| `Status(code int)`                                           | write status code only                   |
| `Header(name, value string)`                                 | set a response header                    |
| `Json(code int, v any)`                                      | JSON-encode `v` and write                |
| `Text(code int, text string)`                                | plain-text response                      |
| `Html(code int, html string)`                                | HTML response                            |
| `Template(code int, tmpl *template.Template, data any)`      | render an `html/template`                |
| `RedirectTemporary(url string)`                              | 307 redirect                             |
| `RedirectPermanent(url string)`                              | 308 redirect                             |
| `Error(code int, err error)`                                 | write error message from `err`           |

---

## Generated server behaviour

Every project generated by SnAPI includes the following out of the box:

- **Standard `net/http` mux** — no custom router or extra dependencies.
- **Graceful shutdown** — `SIGINT` / `SIGTERM` trigger an orderly stop,
  running all `@snapi.teardown` hooks and handler struct `Destructor` methods
  before the process exits.
- **Handler struct lifecycle** — each handler struct (see [annotations.md](annotations.md))
  gets a single package-level instance. Its optional `Constructor` is called
  before the server starts and its optional `Destructor` is called on shutdown.
- **Swagger UI + OpenAPI spec** — opt-in via `--swagger <path>` on
  `serve`/`watch`/`build`. Omit the flag to disable entirely.
